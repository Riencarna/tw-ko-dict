# 台韓 사전 — 대만 중국어–한국어 사전

대만에서 쓰는 중국어(번체자·주음부호·대만식 발음과 어휘)를 한국어로 찾아보는 웹 사전입니다.

- 번체자, 한국어, 병음, 주음부호(ㄅㄆㄇ), 영어로 검색
- 대만식 발음 우선 표시, 본토 표현·발음과의 차이 안내
- 손으로 써서 찾기(검색창의 연필 버튼, 인터넷 없이 동작)
- 두 글자 이상인 단어에서 글자를 누르거나 예문 속 단어를 누르면, 화면을 옮기지 않고 그 자리에서 뜻을 표시
- 단어장, 최근 본 단어, 내 단어 추가
- 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있고, 한 번 연 뒤에는 오프라인에서도 열립니다

## 데이터

- `data/ko-data*.js` — 직접 작성한 한국어 뜻풀이
- `data/measure-data.js` — 명사와 함께 쓰는 양사(대만식, CC-CEDICT의 CL 정보를 참고해 직접 정리)
- `data/cedict-data.js` — [CC-CEDICT](https://cc-cedict.org/)를 가공한 영어 뜻풀이
  (CC BY-SA 4.0, `tools/build_cedict.py`로 변환). 한국어 뜻풀이가 없는 단어에 쓰입니다.
- `lib/hanzilookup.min.js` — 필기 인식 엔진 [HanziLookupJS](https://github.com/gugray/HanziLookupJS) (GNU GPL)
- `data/hanzi-strokes.js` — 필기 인식용 획 데이터(HanziLookupJS의 `mmah.json`,
  [Make Me a Hanzi](https://github.com/skishore/makemeahanzi)에서 파생, Arphic Public License). 자세한 내용은 `lib/NOTICE.txt`.

## 고쳐서 올리기

```
python -I tools/deploy.py <GitHub계정>/<저장소이름>
```

바뀐 파일만 GitHub에 올립니다(GitHub CLI `gh` 로그인 필요). 평소에는 `휴대폰에 올리기.bat`를 실행하면 됩니다.
바뀐 파일은 모두 커밋 하나로 묶어 올리므로 GitHub Pages 배포도 한 번만 일어납니다(보통 1분 안에 반영).
뒤에 `--dry-run`을 붙이면 무엇이 올라갈지와 버전만 보여 주고 아무것도 올리지 않습니다.

## 아이콘

- 지금 아이콘은 H5 '단어 카드'(台 카드와 한 카드가 겹친 모습)입니다. 원본은 `design/logo/final/H5-icon.svg`,
  안드로이드용(둥글게 잘려도 남도록 80%로 줄인 것)은 `H5-icon-maskable.svg`입니다.
  글자는 Noto Sans KR(SIL OFL 1.1, 로고에 써도 되는 무료 글꼴)로 씁니다.
- `icon-512.png`·`icon-192.png`·`icon-maskable-512.png`는 원본 SVG를 이 PC의 Edge로 그려 굳힌 것입니다.
  `icon.svg`에는 글꼴이 없는 기기에서도 같게 보이도록 `icon-512.png`를 그대로 넣었습니다.
- 아이폰 홈 화면의 아이콘은 홈 화면에 추가할 때 한 번 저장되므로, 아이콘을 바꾸면 홈 화면에 다시 추가해야 바뀝니다.
- 고른 과정: 1차 시안(A~F)과 2차 시안(G~K)은 `design/logo-options.html`, H 변형(H1~H6)은 `design/logo-h.html`.
  기준은 "설명 없이 읽히는가"(한국 사람·대만 사람 각각, 사전으로 보이나, 작게 줄여도 읽히나)였습니다.
  예전 아이콘은 `design/logo/old-icon/`에 있습니다. `design/` 폴더는 업로드되지 않습니다.

## 버전

- 버전 번호는 `app.js` 맨 위의 `VERSION`·`VERSION_DATE`에 있고, 사전 첫 화면 맨 아래와 '내 단어 → 도움말 → 버전'에 보입니다.
  휴대폰에서 이 번호가 바뀌었으면 새 버전이 적용된 것입니다.
- `sw.js`의 `CACHE` 이름은 `'twko-' + 버전`으로 같게 둡니다.
- 큰 개선은 가운데 자리(1.1 → 1.2)를 직접 올립니다. 올리는 걸 잊어도 `tools/deploy.py`가
  앱 파일이 바뀌었는데 번호가 그대로인 것을 찾아 끝자리를 올리고(1.1.0 → 1.1.1) 날짜를 오늘로 바꿉니다.

- 영어 참고 사전(`data/cedict-data.js`)은 따로 저장해 버전이 바뀌어도 다시 받지 않습니다.
  이 파일을 새로 만들었을 때만 `sw.js`의 `BIG_CACHE` 숫자를 올립니다.
